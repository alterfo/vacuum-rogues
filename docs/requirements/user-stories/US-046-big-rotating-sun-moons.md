# US-046: Крупное вращающееся солнце + спутники у планет

> Эпик: [EPIC-004](../epics/EPIC-004-grand-system-radar-background.md) · Канон: SOURCE-OF-TRUTH §3

## User Story
**Как** игрок
**Хочу** чёткие, «живые» объекты переднего плана
**Чтобы** система выглядела как в оригинале: большое вращающееся солнце, у планет — спутники

## Статус: Done

## Acceptance Criteria
```gherkin
Scenario: Большое чёткое вращающееся солнце
  Given я в полёте в системе
  Then звезда крупная (R≈170px), с короной и турбулентной поверхностью
  And поверхность вращается со временем (корона — мягкая, тело — чёткое)

Scenario: Спутники у планет
  Given у планеты есть спутники (детерминированно по id, 0–2)
  Then они вращаются вокруг планеты по наклонной орбите (проходят спереди/сзади)
```

## Реализация
`SpaceFlightScene.createStar`: корона (blurred) + вращаемый `starSurface`
(диск + seeded-пятна + маска по диску), `updateStar` крутит поверхность.
`PlanetSprite.createMoons`/`update`: 0–2 спутника (seed `moon_<planetId>`),
локальная орбита с squash. Объекты переднего плана не блюрятся (фон — отдельный
blurred-контейнер).
