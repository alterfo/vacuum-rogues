Бортовой журнал (F1)


Бортовой журнал позволяет делать собственные записи. Сохранять новости.

Чтобы сделать запись:
1. Введите текст в окне.
2. Нажмите кнопку "Добавить".



Совет. Для того чтобы сохранить запись на панели навигации, щелкните по значку , размещенному на полоске с датой этой записи. Теперь вы в любое время можете снова прочитать эту запись, просто подведя курсор мыши к значку на панели навигации.
Для того чтобы удалить запись из журнала, щелкните по значку , размещенному на полоске с датой этой записи.
Примечание. Для удаления всех записей из журнала нажмите клавиши Ctrl+Delete. Чтобы выгрузить записи из журнала во внешний txt-файл нажмите клавиши Ctrl+Inseret. Нажатие клавишей Shift + Backspace позволяет стирать сразу весь текст в окне ввода текста.


Дополнительно при посадке на планету или базу в бортовой журнал закачиваются свежие новости из информационного центра для их дальнейшего просмотра (максимальное количество новостей задается в настройках игры).

Чтобы переключиться в режим новостей:
• Нажмите на кнопку "NEWS" в нижней части окна.

Совет. Для того чтобы запомнить интересную вам новость, щелкните по значку , размещенному справа на полоске с датой этой новости. Теперь вы в любое время можете снова прочитать эту новость, просто подведя курсор мыши к значку на панели навигации.
Примечание. Для удаления всех новостей из журнала, находясь в космосе, незаселенной планете нажмите клавиши Ctrl+Delete.


Чтобы переключиться в режим журнала:
• Нажмите на кнопку "Лупа" в левой нижней части окна.
