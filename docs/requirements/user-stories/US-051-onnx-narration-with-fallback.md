# US-051: ONNX-генерация текста узла с фоллбэком

> Эпик: [EPIC-005](../epics/EPIC-005-text-quests-onnx.md) · Канон: SOURCE-OF-TRUTH §8, §10

## User Story
**Как** игрок
**Хочу** чтобы описания ситуаций и реплики NPC были живыми и разнообразными
**Чтобы** текст-квесты не повторялись дословно от прохождения к прохождению

## Статус: Planned

## Acceptance Criteria

```gherkin
Scenario: Генерация текста узла моделью
  Given активен узел текст-квеста со структурированным промптом
  And диалоговая ONNX-модель доступна
  When игра запрашивает текст узла
  Then текст генерируется моделью в Web Worker (не на главном потоке)
  And соответствует фактам ситуации (роль NPC, тон, ставка)

Scenario: Фоллбэк без модели
  Given модель недоступна или инференс не удался
  When игра запрашивает текст узла
  Then возвращается детерминированный шаблонный текст узла
  And квест проходим без модели (выборы и исходы не зависят от текста)
```

## Дизайн (для реализации)
- Интерфейс `QuestNarrator { narrate(prompt: NarrationPrompt): Promise<string> }`.
- `OnnxQuestNarrator` → `ONNXModelRegistry.infer()` (воркер, ленивая загрузка,
  кеш в IndexedDB); `preprocessInput`/`postprocessOutput` в адаптере.
- `TemplateQuestNarrator` — детерминированный шаблон по `textKey`/фактам (образец
  — `FallbackEngine`). Выбор реализации — как у `NpcBrain` (Onnx→Rule fallback).
- **Граф/исходы не зависят от текста** → тесты мокают нарратор, реальный ONNX не
  нужен в unit-тестах.

## Затрагиваемые файлы (план)
- `src/systems/quests/QuestNarrator.ts` — интерфейс + выбор реализации.
- `src/ai/adapters/OnnxQuestNarrator.ts` — адаптер инференса.
- `src/ai/FallbackEngine.ts` — шаблонный фоллбэк.
- `src/tests/questNarrator.test.ts` — фоллбэк-путь + контракт интерфейса (мок).
