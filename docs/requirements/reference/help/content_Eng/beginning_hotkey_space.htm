Hot keys: space




Esc — cancel, pause, open the system menu and resume the game
F1 — open the flight log
         Up, Down — navigation
         Page Up, Page Down — navigation
         Mouse Wheel — navigation
         Ctrl+Delete — clear the flight log
         Ctrl+Insert — dump the flight log entries into a .txt file
F2 — save the current game
F3 — load a previously saved game
F5 — quick save
F8 — load a quick save
F9 — snap a screenshot
F10 — pause game
F11 — clear the message log
Space — flight, end turn
Shift+Space — make a stop at the end of each day of flight
S — space ship
       Shift+Mouse 2 — right-click an item with a Shift key pressed to immediately throw away this item into the space
       K — turn the camouflage on/off
       Mouse 2 — turn the camouflage on/off, click the hull
       Ctrl+digit from 1 to 3 — save the equipment configuration
       digit from 1 to 3 — restore the equipment configuration
       Mouse Wheel — navigation in the hatch
       Right, Left — navigation in the hatch
R — ranger rating
       Up, Down — navigation
       Page Up, Page Down — navigation
       Mouse Wheel — navigation
C — focus the camera on the player's ship
I — scanning
T — chat
H — watch a movie
       Space — watch, pause game
W — show, hide weapon
        1, 2, 3, 4, 5 — choose weapon
M — open the galaxy map
        Alt — hold this key down to measure the distance between any stars
Right, Left, Up, Down — navigation
Mouse 2 — depending on the settings: chat, scan, change order
Mouse 2 — delete a message, a completed task, price from the board
Num 0 — select all items in the grip radius
Num . — select all items in the system
Insert — receive prices from all planets and bases located in the radar radius
X — focus the camera on the closest dominator
Z — focus the camera on the farthest dominator
F — turn the boost on/off
1, 2, 3, 4, 5 — choose weapon
