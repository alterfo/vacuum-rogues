# Вакуумные Пройдохи

**Вакуумные Пройдохи** — браузерная космическая RPG/стратегия с открытым миром,
крошечными нейрополитиками на чистом TypeScript (MLP) и правиловым движком
`FallbackEngine` для диалогов и тактического ИИ.

## Быстрый старт

### Предварительные требования

- Node.js 20+
- npm или pnpm

### Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для production
npm run build

# Предпросмотр production-сборки
npm run preview

# Запуск тестов
npm test

# Проверка линтером
npm run lint
```

## Архитектура

### Технологический стек

- **TypeScript 5.4+** — строгая типизация
- **Vite 5.2+** — сборка и dev-сервер
- **PixiJS 8.0+** — рендеринг (WebGL / Canvas2D)
- **Чистый TS MLP** (`src/tests/playtest/letsplay/mlp.ts`) — крошечные нейрополитики без рантайма нейросети
- **IndexedDB** — сохранения

## Игровой процесс

### Фракции

| Фракция     | Специализация                        |
| ----------- | ------------------------------------ |
| Окраинники  | Торговля, ремонт, надёжность         |
| Бастионы    | Военные технологии, броня            |
| Синдикат    | Контрабанда, скрытность, скорость    |
| Парадоксы   | Уникальные модули, непредсказуемость |
| Прогрессоры | Технологии, наука, дроны             |

### Основные механики

- 🚀 Свободные перелёты между звёздными системами
- 💰 Торговля товарами с динамическими ценами
- ⚔️ Бои в реальном времени с активной паузой — при обстреле игра замирает и даёт выбрать цель и оружие (стиль Space Rangers / FTL)
- 📜 Квесты с ветвящимися сюжетами
- 🌍 Живая галактика — NPC живут независимо от игрока
- 🛰️ Случайные находки в полёте — при входе в систему могут встретиться дрейфующий обломок (обыскать), аномалия (просканировать) или сигнал бедствия (откликнуться): выбор «вмешаться / уйти» приносит кредиты, груз и репутацию — но иногда оборачивается ловушкой или засадой (бой)
- 🧠 Эндшпиль «Нейронный натиск» — Сверхразум со временем захватывает системы и расползается по галактике; если его игнорировать, он поглощает галактику (поражение). Победа — прорваться к ядру Сверхразума и уничтожить его
- ♻️ Новая игра+ — после победы над Сверхразумом можно начать новый, более сложный цикл, перенеся часть прогресса (ограниченную долю кредитов, ранг и фракцию капитана; сложность повышается на одну ступень)
- 🏦 Галактический банк (АБС) — счета, выписки, вклады и кредиты, наглядная визуализация двойной записи и шины
- 🎚️ Режимы сложности (выбор при старте новой игры):
  - **Бог** — корабль не гибнет: при нуле прочности он остаётся жив, но «выведен из строя» (downed) — не может стрелять и совершать гиперпрыжок, пока его не отремонтируют выше порога прочности
  - **Средний** — стандартная сложность (поведение по умолчанию)
  - **Сложный** — больше пиратов и Сверхразума (больше враждебных систем) и крупнее гарнизоны
- 💀 Гибель корабля (в режимах Средний/Сложный) — экран «Корабль уничтожен» с откатом к последнему взлёту (автосейв в слот «auto») или началом новой игры (в режиме «Бог» корабль не уничтожается)
- 🆘 Системное меню в полёте — кнопка **[МЕНЮ]** в левом верхнем углу всегда доступна: «Сохранения» (полный экран именованных слотов), «Загрузить сохранение» (откат к автосейву с подтверждением) или «В главное меню» — выход из любого тупика (обстрелян, прочность < 30%, двигатели остановлены, нет кредитов)
- 💾 Экран сохранений — открывается из главного меню и из системного меню в полёте: список слотов (автосейв + ручная сетка) с именованными ручными сохранениями (создать / переименовать-перезаписать / удалить) и загрузкой любого слота. «Продолжить» в главном меню возобновляет самое свежее осмысленное сохранение среди всех слотов (а не только автосейв — учитывается и более поздний ручной сейв, и пропускаются экраны победы/поражения)
- ❓ Контекстная помощь — при первом входе на любой экран всплывает короткая подсказка (что это и что делать); кнопка **«?»** вверху справа открывает её в любой момент. «Показать обучение заново» в главном меню возвращает все подсказки
- ⚙️ Единая панель настроек — кнопка **«Настройки»** в главном меню открывает скорость игры (1×/2×/4×), размер шрифта (S/M/L) и выбор языка (Русский/English, по умолчанию русский); выбор сохраняется и применяется при «Продолжить». Переключатель нейро-ИИ показывается только в dev-сборке (в проде он был бы неактивен, поэтому скрыт)
- ♿ Специальные возможности — палитра для дальтоников (применяется сразу, в т.ч. к уже отрисованным кораблям в полёте), режим «меньше движения» и переназначение горячих клавиш полёта; доступны из «Настроек» в главном меню и из панели ♿ в полёте
- 🎵 Адаптивная музыка — фоновый трек реагирует на происходящее: при бое плавно включается напряжённый боевой трек (отдельный — для боя у ядра Сверхразума), по окончании боя музыка так же плавно возвращается к фоновой; при критической прочности корпуса звучит сигнал тревоги, а гиперпрыжок, торговля и повышение звания сопровождаются звуковыми эффектами

### Управление

- **Пробел** — выполнить проложенный маршрут (запустить ход в полёте)
- **Enter** — подтвердить основное действие в окне (например, первый ответ в диалоге)
- **Esc** — закрыть окно / отменить проложенный маршрут
- **Двойной клик** по системе на карте галактики — прыжок (одиночный клик — информация о системе)
- **J** — журнал заданий, **I** — инвентарь
- **[МЕНЮ]** (кнопка в левом верхнем углу) — системное меню в полёте: сохранения (именованные слоты) / загрузить сохранение / выйти в главное меню
- **«?»** (кнопка вверху справа) — открыть подсказку по текущему экрану
- **«Настройки»** (кнопка в главном меню) — скорость игры, размер шрифта, язык (Русский/English) и специальные возможности (палитра для дальтоников, режим «меньше движения», переназначение клавиш полёта); переключатель нейро-ИИ доступен только в dev-сборке

**Сенсорное управление (телефон / планшет).** Игра рассчитана на десктоп, но уже играбельна на тач-экранах:

- **Тап** по точке / планете / станции / кораблю — проложить курс или выбрать цель; повторный тап — выполнить ход (аналог одиночного/двойного клика мышью).
- **Щипок двумя пальцами** — масштаб (зум к середине между пальцами).
- Экранная кнопка **«✕»** — отмена / закрыть окно (аналог Esc); кнопки **[ХОД]**, **[КВЕСТЫ]**, **[I]** заменяют горячие клавиши Пробел / J / I.

### Добавление новой сцены

1. Создать класс, наследующий `GameScene`
2. Реализовать методы `initialize()`, `update()`, `destroy()`
3. Добавить `case` в `src/core/services/SceneFactory.ts`
4. Добавить `SceneType` в `src/types/index.ts`

### Тренировка нейрополитики игрока

Нейрополитики — крошечные MLP на чистом TypeScript (без ONNX-рантайма). Пайплайн
behavioural cloning:

1. Сгенерировать датасет: `src/tests/playtest/letsplay/exportBcData.ts`
2. Обучить и экспортировать веса в JSON: `tools/ai/train_player.py` (см. `tools/ai/README.md`)
3. Положить `*.weights.json` туда, где их грузит `NeuralPolicy` (dev-only); паритет
   пинится тестом `weightsContract.test.ts`

Для диалогов / тактического ИИ используется правиловый `FallbackEngine` (`src/ai/FallbackEngine.ts`) — без файла модели.

## Деплой

### GitHub Pages (текущий прод)

Push в `master` запускает `.github/workflows/notify-alterfo.yml`, который шлёт
`repository_dispatch` на `alterfo/alterfo.github.io-src`; тот фетчит свежий
`master` этого репозитория и пересобирает GitHub Pages — ручной bump не нужен.

### Ручной деплой

```bash
npm run build
# Загрузить dist/ на любой статический хостинг
```

## Переменные окружения (для CI/CD)

- `BLOG_DISPATCH_TOKEN` — секрет этого репозитория (PAT): создаёт
  `repository_dispatch` на `alterfo/alterfo.github.io-src` для пересборки прода
  (см. `.github/workflows/notify-alterfo.yml`).
- `GITHUB_SHA` — выставляется GitHub Actions автоматически; используется как
  запасной источник git-SHA для диагностики в форме отзыва (основной — локальный
  `git rev-parse` сборочного чекаута; см. `vite.config.ts`).
