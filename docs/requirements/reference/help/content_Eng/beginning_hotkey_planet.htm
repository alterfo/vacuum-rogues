Start > Hot keys > Planet, RC, MB, SB, PB, BC
    


Hot keys: a planet, RC, MB, SB, PB, BC (see below)



Esc — cancel, pause, open the system menu and resume the game
F1 — open the flight log
         Up, Down — navigation
         Page Up, Page Down — navigation
         Mouse Wheel — navigation
         Ctrl+Delete — clear the log
         Ctrl+Insert — dump the flight log entries into a .txt file
F2 — save the current game
F3 — load a previously saved game
F5 — quick save
F8 — load a quick save
F9 — snap a screenshot
F11 — delete all the prices from the message board
F12 — delete all the prices from the message board
S — space ship
        ALT+Mouse 2 — right-click an item with a Shift key pressed to immediately remove this item to the storage
        K — turn the camouflage on/off
        Mouse 2 — turn the camouflage on/off, click the hull
        Ctrl+digit from 1 to 3 — save the equipment configuration
        digit from 1 to 3 — restore the equipment configuration
        Mouse Wheel — navigation in the hatch
        Right, Left — navigation in the hatch
R — Ranger rating
       Up, Down — navigation
       Page Up, Page Down — navigation
       Mouse Wheel — navigation
I — information center
       Up, Down — navigation
       Page Up, Page Down — navigation
       Mouse Wheel — navigation
       I — search
       F — search
              Shift+Backspace — delete the entire text in the search window
              Mouse 1 — click i to save the result
Ctrl — hold down the key to display the dialogue of partial fuelling/charging
Ctrl+I — move all items from the hatch into the storage
Ctrl+O — move all the items from the storage into the hatch
U — load the missiles located in the slots
Y — load the missile located in the hatch
G — government building
       Up, Down — navigation
       Page Up, Page Down — navigation
       Mouse Wheel — navigation
       Insert — save the governmental message
       Mouse 1 — click i to save the governmental message
H — hangar
       F — takeoff
       B — refuel
       A — repair hull
T — trading center
       Mouse 1 — click i to save the price
       Home, End — while trading: max., min. of goods
       Right, Left — while trading: increase, reduction of goods amount
       Mouse Wheel — while trading: increase, reduction of goods amount
E — Equipment shop
       Right, Left, Up, Down — navigation
       Mouse Wheel — increase, reduction of goods amount
P — planet (only on the planets)
M — galaxy map
        Alt — hold this key down to measure the distance between any stars
Mouse 2 — delete a message, a completed task, a price from the message board
Space — a day ahead
Alt+Mouse 2 — right-click an item in the storage with the key pressed to immediately move this item into the hatch
Mouse Wheel — navigation in the hatch
Up, Down — navigation in the hatch
click an item with Mouse 2 — send from the space ship to the storage/move from the storage into the space ship.
click an item with Ctrl + Mouse 2 — quick sale.

RC — Ranger Center, MB — Military Base, SB — Scientific Base, PB — Pirate Base, BC — Business Center
