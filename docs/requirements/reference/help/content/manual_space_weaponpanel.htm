Оружейная панель (W)


Нажатие кнопки "Показать/скрыть оружие" раскрывает оружейную панель, состоящую из 5 слотов, в каждый из которых может быть установлено одно орудие. В результате корабль может иметь до 5 орудий, одновременно готовых к бою, если его корпус позволяет это. Оружейная панель служит для наведения имеющихся орудий на цели (вражеские корабли, астероиды). Можно навести на одну цель сразу несколько орудий, а также наводить разные орудия на разные цели. Орудия, лежащие в трюме, стрелять не могут, однако вы можете их установить и подготовить к бою.


Чтобы установить орудие, лежащее в трюме, в оружейный слот:
1. Нажмите кнопку "Корабль" (S).
2. Щелкните по орудию, лежащему в трюме. Курсор мыши примет форму руки, держащей орудие.
3. Щелкните по оружейному слоту, в который вы хотите установить орудие.

Чтобы закрыть оружейную панель:
Нажмите кнопку "Показать/скрыть оружие" еще раз.

О стрельбе читайте в разделе "Стрельба из орудий".
