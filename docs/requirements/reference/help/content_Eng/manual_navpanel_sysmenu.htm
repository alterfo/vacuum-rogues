System menu (Esc)


The system menu consists of six buttons (the relative hot keys are indicated in brackets)



Continue (Esc) - close the system menu and resume the game.

Save (F2) - save the current game.

Load (F3) - load a previously saved game.

Settings (C) - change game settings.

Help (H) - open this guide.

Exit (E) - quit the current game and go back to the main menu.

An additional button, press it to close this window "Cancel" in form of a dash sign.
