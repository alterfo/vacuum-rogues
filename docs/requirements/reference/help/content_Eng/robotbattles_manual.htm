Manual control mode


There are two variants of controlling a robot. Yoг can control it in the strategic mode and in the manual control mode.
You can activate this mode, if you press the 'Manual control' button on the selected robot.



The camera moves into the overhead position (above the robot). You can change its height with the help of the buttons: Page Up and Page Down or the mouse wheel.

Controlling a robot:
Move forward - w (or Up arrow)
Move back - s (or Down arrow)
Move left - a (or Left arrow)
Move right - d (or Right arrow)
Shoot - hit the left mouse button
Move the robot body to choose the firing direction with the help of the mouse.

Locator
In the manual control mode the minimap is replaced with the locator. You can see the enemies on it.



Press 'Exit' button to exit the manual control mode in the bottom right corner or Esc button on the keyboard.
