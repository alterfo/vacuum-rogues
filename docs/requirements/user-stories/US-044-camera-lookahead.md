# US-044: Камера с упреждением по ходу движения

> Эпик: [EPIC-004](../epics/EPIC-004-grand-system-radar-background.md) · Канон: SOURCE-OF-TRUTH §3

## User Story
**Как** игрок
**Хочу** чтобы при движении камера показывала пространство впереди корабля
**Чтобы** я успевал реагировать на ситуацию по курсу

## Статус: Done

## Acceptance Criteria
```gherkin
Scenario: Камера ведёт вперёд при движении
  Given корабль летит
  Then фокус камеры смещён вперёд по курсу (корабль ближе к «хвосту» экрана)
  And величина упреждения растёт со скоростью

Scenario: Возврат к центру при остановке
  Given корабль остановился
  Then упреждение плавно затухает, корабль возвращается к центру
  And после этого ручной пан камеры снова работает
```

## Реализация
`SpaceFlightScene.focusCameraWithLead`: целевой фокус = позиция корабля +
heading·lead, где lead ∝ доле макс. скорости (`ShipPhysics.getSpeedFraction`),
до ~34% полуэкрана. Сглаживание `camLead` каждый кадр; `updateCamera` ведёт пока
есть движение или остаточное упреждение.
