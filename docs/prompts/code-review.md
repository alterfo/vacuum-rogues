# Шаблон: Code Review

## Что проверить

### Архитектура
- [ ] Соблюдается направление зависимостей (Presentation → Systems → Domain)
- [ ] Нет циклических зависимостей
- [ ] Используются существующие паттерны проекта

### Код
- [ ] Нет дублирования кода
- [ ] Именование понятное и консистентное
- [ ] Функции/методы небольшие и выполняют одну задачу
- [ ] Нет magic numbers/strings

### PixiJS (для UI кода)
- [ ] Event listeners добавляются в initialize(), удаляются в destroy()
- [ ] Нет утечек памяти (Graphics/Container очищаются)
- [ ] Используется eventMode вместо deprecated interactive
- [ ] UI элементы добавляются в uiLayer, игровые - в gameLayer

### Безопасность
- [ ] Нет инъекций (SQL, XSS, command injection)
- [ ] Валидация пользовательского ввода
- [ ] Нет чувствительных данных в коде

### Тесты
- [ ] Новый код покрыт тестами
- [ ] Тесты проверяют граничные случаи
- [ ] Тесты читабельны и понятны

### Performance
- [ ] Нет N+1 проблем
- [ ] Тяжелые операции не блокируют main thread
- [ ] Нет лишних перерисовок UI

## Формат комментариев
```
[MUST FIX] - Критично, блокирует мерж
[SHOULD FIX] - Важно, но можно поправить позже
[NIT] - Мелочь, по желанию
[QUESTION] - Нужно уточнение
```
