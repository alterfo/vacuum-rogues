# US-022: Игровая дата вместо счётчика дней (год 4000)

> Канон: SOURCE-OF-TRUTH §3 (полёт по игровым дням). Сквозная UI-история.

## User Story
**Как** игрок
**Хочу** видеть внутриигровую дату, а не «День: N»
**Чтобы** время ощущалось как календарь, начиная с года 4000

## Статус: Done

## Acceptance Criteria

```gherkin
Scenario: Дата в начале игры
  Given начинается новая игра (gameDays = 0)
  Then в полёте отображается "1 января 4000 г."

Scenario: Дата идёт во время полёта
  Given корабль летит и проходят игровые дни
  Then дата на экране обновляется (день → месяц → год)
  And после 30 дней наступает следующий месяц
  And после 360 дней наступает следующий год (4001 …)
```

## Technical Context
- `src/utils/gameCalendar.ts` — `GAME_START_YEAR = 4000`, `toGameDate`,
  `formatGameDate`. Календарь 12 × 30 = 360 дней (без сложных правил).
- Внутренний счётчик `Galaxy.gameDays` сохраняется (на нём завязаны квесты);
  меняется только **отображение** на дату.
- Применено в `SpaceFlightScene` (создание и обновление счётчика).

## Out of Scope
- Дюрации («Перелёт: X дн.») остаются в днях — это интервалы, не даты
- Пересчёт «пиксели-на-день» при масштабировании системы — см. EPIC-004
