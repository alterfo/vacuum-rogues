# Space Rangers: Neural Onslaught - Геймдизайн документ

## Концепция игры

**Space Rangers: Neural Onslaught** - браузерная космическая RPG/стратегия, вдохновленная классической серией Space Rangers. Игрок управляет космическим рейнджером, исследуя галактику, торгуя, выполняя квесты и сражаясь с врагами.

**Уникальность**: Локальные ONNX-модели для генерации диалогов и тактического AI.

## Система кораблей

### Характеристики
- **Hull HP** - прочность корпуса (0 = уничтожение)
- **Shields** - щиты (восстанавливаются)
- **Energy** - энергия для способностей
- **Speed** - скорость перемещения
- **Evasion** - уклонение от атак

### Модули (3 слота)
- **Weapon** - увеличивает урон
- **Shield** - увеличивает защиту
- **Engine** - увеличивает скорость/уклонение

## Система квестов

### Типы квестов
| Тип | Описание |
|-----|----------|
| DELIVERY | Доставка груза из A в B |
| BOUNTY | Уничтожить цель |
| ESCORT | Сопровождение корабля |
| DIPLOMACY | Переговоры между фракциями |
| EXPLORATION | Исследование системы |

### Дедлайны и штрафы
- Квесты имеют дедлайн в игровых днях
- При просрочке применяется штраф:
  - Потеря репутации (обязательно)
  - Штраф кредитами (опционально)
  - Тюремный срок (опционально)

## Боевая система

### Тактический бой
- Гексагональная сетка 9x9
- Пошаговый режим
- Очки действия на ход

### Terrain
| Тип | Эффект |
|-----|--------|
| EMPTY | Нет эффекта |
| ASTEROID | Блокирует движение |
| DEBRIS | Замедляет движение |
| NEBULA | Скрывает корабли |

### AI противников
- Rule-based AI для базовых врагов
- ONNX PPO-модель для продвинутых противников

## Репутация

- Репутация отдельная с каждой фракцией (-100 до +100)
- Влияет на: цены, доступные квесты, реакцию NPC
- Негативная репутация: атаки патрулей, отказ в торговле

## Прогрессия

### Опыт и уровни
- Опыт за квесты, бой, исследование
- Максимальный уровень: 99
- Каждый уровень дает очки навыков

### Древо навыков
| Ветка | Эффект |
|-------|--------|
| Piloting | Скорость, уклонение |
| Tactics | Урон, критические удары |
| Trading | Лучшие цены |

| Hacking | Взлом систем |

## Галактика

### Структура
- 20-50 звездных систем
- Гексагональная карта для навигации
- Warp-соединения между системами

### Типы звезд
| Тип | Особенности |
|-----|-------------|
| RED_DWARF | Малые системы |
| YELLOW_DWARF | Стандартные системы |
| BLUE_GIANT | Большие системы, редкие ресурсы |
| WHITE_DWARF | Старые системы |
| NEUTRON | Опасные зоны |
| BLACK_HOLE | Экстремально опасные |

## Симуляция галактики

- Время течет при перемещении между системами
- 1 варп-прыжок = 1 игровой день
- События происходят независимо от игрока
- Экономика планет меняется со временем

## Технические ограничения

### Для UI-разработки (PixiJS 8)
- Event handlers только в initialize(), очистка в destroy()
- Использовать eventMode вместо interactive
- gameLayer для игровых объектов, uiLayer для UI
- Не забывать очищать Graphics при перерисовке

### Для AI (ONNX Runtime)
- Inference только через Web Workers
- Модели кэшируются в IndexedDB
- Fallback на hardcoded ответы при ошибке загрузки
