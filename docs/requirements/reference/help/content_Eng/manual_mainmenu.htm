Main menu screen


After the game launch you see the main menu screen, which displays the game name, game version number (in the bottom left corner) and the main menu buttons:

• New game - start a new game.

• Load game - load a previously saved game.

• Settings - adjust the game parameters to achieve the optimal performance at your PC.

• High score - check your results and compare them with the best achievements.

• Credits - find out who was breaking their necks over the creation of this game.

• Exit - quit playing and return to Windows.
