New features of the Space Rangers: Reboot



New features of the game compared with the previous version of the title:

• 20 new text quests.


• 27 new maps for planetary battles.


• 10 new maps in the hyperspace.


• Over 50 new governmental quests.


• New unique equipment.


• New game modes: sequential completion of all quests and planetary battles.


• The galaxy search system upgraded.
