System requirements


Minimal

  Operating system Windows XP SP3
  CPU Intel Pentium 4 2.5 GHz / AMD Athlon XP 3200+ (2.2 GHz)
  RAM 1 Gb
  HDD free space 2 Gb
  Graphics card GeForce 7800 GT 512 Mb / Radeon 1800 Pro 512 Mb
  Controls Mouse and keyboard



Recommended

  Operating system Windows XP SP3 / Windows 7 / Windows 8
  CPU Intel Core 2 Duo 2.4 GHz / AMD Athlon 64 X2 4800+ (2.4 GHz)
  RAM 2 Gb
  HDD free space 3 Gb
  Graphics card GeForce 8600 GT 512 Mb / Radeon X3550 Pro 512 Mb
  Controls Mouse and keyboard



For the correct game operation the following software should be installed at your PC: MS DirectX 9.0c and MS Visual Studio C++ 2010 Redistributable.
The following operating systems are not supported: Windows 95, Windows 98/98SE, Windows NT4, Windows ME, Windows 2000, Windows 8 RT.
