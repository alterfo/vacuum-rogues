Системные требования


Минимальные

  Операционная система Windows XP SP3
  Процессор Intel Pentium 4 2.5 ГГц / AMD Athlon XP 3200+ (2.2 ГГц)
  Память 1 Гб
  Свободное место на HDD 2 Гб
  Видеокарта GeForce 7800 GT 512 Мб / Radeon 1800 Pro 512 Мб
  Управление Мышь и клавиатура



Рекомендуемые

  Операционная система Windows XP SP3 / Windows 7 / Windows 8
  Процессор Intel Core 2 Duo 2.4 ГГц / AMD Athlon 64 X2 4800+ (2.4 ГГц)
  Память 2 Гб
  Свободное место на HDD 3 Гб
  Видеокарта GeForce 8600 GT 512 Мб / Radeon X3550 Pro 512 Mb
  Управление Мышь и клавиатура



Для корректной работы игры также необходимо наличие в системе следующих программных пакетов: MS DirectX 9.0c и MS Visual Studio C++ 2010 Redistributable.
Не поддерживаются следующие операционные системы: Windows 95, Windows 98/98SE, Windows NT4, Windows ME, Windows 2000, Windows 8 RT.
