# US-035: Поведение NPC — офф-скрин бой, торговля, квесты

> Эпик: [EPIC-003](../epics/EPIC-003-living-galaxy.md) · Канон: SOURCE-OF-TRUTH §6

## User Story
**Как** игрок
**Хочу** чтобы NPC занимались делом независимо от меня
**Чтобы** галактика была опасной и динамичной

## Статус: In Progress (офф-скрин бой и население — Done; торговля/квесты — Planned)

## Acceptance Criteria

```gherkin
Scenario: Офф-скрин бой пиратов  # Done
  Given пират и не-пират находятся в одной системе вне системы игрока
  When срабатывает дневной тик симуляции
  Then пират атакует жертву (урон частями по дням)
  And при обнулении корпуса жертва уничтожается (DEAD)
  And пират получает добычу (кредиты)
  And в системе игрока офф-скрин бой НЕ происходит (корабли там видимы)

Scenario: Поддержание населения  # Done
  Given кто-то из NPC уничтожен
  When срабатывает тик
  Then уничтоженные удаляются, а население восполняется до целевого

Scenario: Торговля двигает рынки  # Planned
  Given NPC-торговец прибывает в систему с рынком
  Then он покупает/продаёт, слегка смещая спрос/предложение
  # Заблокировано: рынки планет пока заглушки (EPIC-001)

Scenario: NPC берут квесты  # Planned
  Given в системе есть доступный квест из общего пула
  Then рейнджер-NPC резервирует его и летит к цели
  # Заблокировано: нет общего пула квестов для NPC
```

## Technical Context
- **Combat**: `NpcSimulator.resolveOffscreenCombat(galaxy, rng, playerSystemId)`
  — группировка present-NPC по системам (кроме системы игрока), пират бьёт
  случайную жертву; урон/ретализация частями (`PIRATE_DAMAGE_FRACTION` и т.п.)
- **Population**: `pruneAndReplenish` — удаляет DEAD, респавнит до цели
- **Dwell**: прибывшие задерживаются ~3 дня (`DEPART_CHANCE`), чтобы успеть
  повзаимодействовать
- **Engine**: `GameEngine.advanceGalaxyDay` передаёт `player.currentSystemId`
