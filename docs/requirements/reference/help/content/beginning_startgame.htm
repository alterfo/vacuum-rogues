Установка и запуск игры

Установка игры

Вставьте диск с игрой "Космические Рейнджеры HD: Революция" в оптический привод вашего компьютера. Окно установки откроется автоматически. Если этого не произошло, то запустите файл setup.exe с диска. Во время установки следуйте появляющимся инструкциям. После завершения установки нажмите кнопку "Запуск игры".

Примечание: в процессе установки игры вам будет предложено установить DirectX 9.0c, если вы уверены, что у вас установлен он, либо более новая версия, вы можете отказаться.

Запуск игры

Щелкните по значку с названием игры на рабочем столе компьютера.

или
1. Нажмите кнопку Пуск (Start)
2. Выберите меню Программы (Programs) - 1С - Космические Рейнджеры HD: Революция
3. Щелкните по ярлычку Космические Рейнджеры HD: Революция

или
1. Запустите Мой Компьютер (My Computer)
2. Откройте папку, в которую была установлена игра
3. Запустите файл rangers.exe
