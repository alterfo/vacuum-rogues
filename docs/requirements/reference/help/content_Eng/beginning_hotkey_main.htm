Hot keys: main menu



Esc — open the exit menu
N — new game
F3
L  — load a save game
С — change the game settings
Q — open the list of text quests
        R — reload a quest
F — open a list of hyper-space battles
R — open a list of planetary battles
M — open mod manager
        Ctrl+A — turn on all mods in a section
        Ctrl+Z — turn off all mods in a section
        Enter — apply changes
        Esc — cancel changes
