# EPIC-001: Торговая система

## Описание
Полнофункциональная система торговли между игроком и планетами/станциями.

## Бизнес-ценность
Торговля - ключевая механика геймплея, позволяющая игроку зарабатывать кредиты и ресурсы для прогресса.

## Acceptance Criteria (Epic Level)
- [x] Игрок может торговать на любой планете
- [x] Цена продажи всегда ниже цены покупки на одной планете (нет арбитража)
- [x] Цены различаются между планетами
- [ ] Цены зависят от спроса и предложения (на наполненных рынках)
- [ ] Существует система легальных и нелегальных товаров
- [ ] Торговля влияет на репутацию с фракцией
