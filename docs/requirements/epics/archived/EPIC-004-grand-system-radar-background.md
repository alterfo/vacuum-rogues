# EPIC-004: Масштаб системы, радар-миникарта и фон

> Канон: [SOURCE-OF-TRUTH §3 «Полёт в звёздной системе»](../reference/SOURCE-OF-TRUTH.md#3-полёт-в-звёздной-системе).

## Описание
Приблизить внутрисистемный экран к оригиналу: система **крупнее экрана** (камера
следит за кораблём), миникарта работает как **радар** (вся система + точки
кораблей + рамка обзора + граница системы), фон космоса — заметно красивее
(параллакс, туманности, виньетка).

## Бизнес-ценность
Атмосфера и читаемость, как в оригинале. Масштаб даёт пространство для «живой
галактики» (EPIC-003), радар — ориентацию в большой системе.

## Acceptance Criteria (Epic Level)
- [ ] Орбиты увеличены ×4–5, система крупнее экрана, есть граница системы
- [ ] Камера следует за кораблём; зум и «пиксели-на-день» пересчитаны (Rule 5)
- [ ] Радар показывает всю систему, рамку обзора и точки NPC по фракциям
- [ ] Фон: 3–4 параллакс-слоя звёзд, туманности, виньетка

## Важный нюанс баланса
При ×5 системе перелёты по текущей формуле «500px = 1 день» станут ~в 5 раз
длиннее. Нужно пересчитать скорость/пиксели-на-день, чтобы перелёт
планета→планета остался осмысленным (~3–8 дней), сохранив пошаговость. Сейчас
дата считается из `gameDays` (см. [US-022](../user-stories/US-022-game-date.md)),
формула дней-перелёта — параметр этого эпика.
