# Galactic Horizon — музыкальный трек-лист по ситуациям

Список фоновых треков под состояния игры. Музыка пишется отдельно (ты — фоном),
здесь — ТЗ на настроение/темп/инструментал и **ключ состояния**, к которому трек
привяжется в коде (будущий `AudioManager` будет кроссфейдить по ключу).

Общие правила:
- Все треки **зацикленные** (seamless loop), длина 1.5–3 мин, плюс отдельный
  «intro»-кусок по желанию.
- Кроссфейд между состояниями 1.5–3 с. Уровень громкости music ≈ −14 LUFS.
- Формат: `.ogg` (основной) + `.mp3` (фоллбэк). Имя: `mus_<key>.ogg`.
- Адаптивность (на будущее): по 2 слоя на ключ — `_calm` и `_intense` — для
  плавного нагнетания (vertical layering) без смены трека.

| Ключ состояния | Ситуация | Настроение | Темп / тон | Инструментал |
|----------------|----------|------------|------------|--------------|
| `explore_calm` | Полёт в мирной системе | Простор, любопытство, одиночество | 60–75 BPM, мажор/лидийский | Пэды, арпеджио-синты, далёкое фортепиано, лёгкий хор |
| `explore_wonder` | Красивая/необычная система (туманности) | Благоговение, «sense of wonder» | 65 BPM, парящий | Струнные swells, glassy bells, женский вокализ |
| `tension_low` | Рядом чужие корабли, неясные намерения | Настороженность | 80 BPM, минор, пульс | Низкий пульс-бас, тиканье, приглушённые струнные |
| `combat` | Бой в космосе | Драйв, опасность | 120–140 BPM | Перкуссия, брасс-стабы, дисторшн-синты, ostinato струнных |
| `combat_boss` | Бой с сильным врагом / флотом | Эпик, угроза | 130 BPM, нарастание | Хор (латынь-стиль), литавры, тяжёлый брасс, орган |
| `overmind` | Близость/тема OVERMIND (древняя угроза) | Чужеродность, ужас | 50–70 BPM, атонально | Гранулярные текстуры, металл-резонансы, суб-бас, обратные сэмплы |
| `warp` | Гиперпрыжок (вылет/влёт) | Импульс, переход | свуш→резолюция, 8–12 с стингер | Восходящий риз, доплеровский свип, удар на выходе |
| `victory` | Победа в бою / завершение квеста | Триумф, облегчение | короткий джингл 6–10 с | Брасс-фанфара, восходящие струнные |
| `defeat` | Поражение / гибель корабля | Утрата | медленно, минор, 8–12 с | Соло-виолончель, угасающий пэд |
| `planet_hub` | На планете (хаб услуг) | Уют, «дом», деловитость | 70–90 BPM, тёплый | Электро-пиано, мягкий грув, этнические перкуссии под фракцию |
| `market` | Торговый центр | Лёгкость, оживление | 90–110 BPM, грувовый | Джаз/lo-fi бас, виброфон, щёлк-перкуссия |
| `equipment_shop` | Магазин оборудования / ангар | Техно, фокус | 85 BPM | Аналоговые секвенсоры, механические сэмплы, мягкий бас |
| `governor_dialogue` | Диалог с губернатором/официалом | Официоз, интрига | медленно, нейтрально | Камерные струнные, фортепиано, сдержанно |
| `text_quest` | Текст-квест (новелла) | Погружение, нарратив | очень мягко, эмбиент | Эмбиент-пэды, сольный инструмент по теме квеста |
| `station_pirate` | Пиратская станция | Опасный шик, фанк | 100 BPM, дерзко | Грязный бас, гитара-вау, брасс-хиты |
| `station_science` | Научная база | Стерильность, тайна | 70 BPM | Чистые синты, glitch-перкуссия, высокие пэды |
| `menu_main` | Главное меню / титул | Зов приключения, тема игры | 75 BPM, тематический | Полный оркестр + синты — «главная тема», лейтмотив игры |
| `news_alert` | Важная новость/событие в инфоцентре | Внимание | стингер 3–5 с | Короткий мотив-сигнал (узнаваемый) |

Приоритет записи (минимальный играбельный набор): `explore_calm`, `combat`,
`planet_hub`, `market`, `menu_main`, `warp` (стингер). Остальное — по мере роста.

Совет: задай **один лейтмотив** (4–6 нот темы игры) и проводи его через
`menu_main` → `explore_wonder` → `victory` — это свяжет саундтрек в единое целое.
