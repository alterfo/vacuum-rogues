Robot builder


When the player's base is selected, you can find in the right bottom corner of the main panel two buttons: "Build turrets" and "Build robots".

How to build a robot:
1. Press the 'Build robots'-button - a window of the robot builder will appear. The game will enter the pause mode, therefore you can can take your time. Each robot consists of a particular set of parts: body, chassis, module, guns. Each of its parts has its own price, which makes the final robot's price.



2. Select the robot's body. The amount of weapon slots (pylons) depends on the body. The more expensive is the body, the more pylons it has and the better is its protection. You can select the parts using one of the following two variants:
Variant 1 Click the active slot with the left mouse button and the parts will start filling the slot one after another.
Variant 2 Click a slot with the right mouse button and select the required part in the pop-up window.

3. Mount the required chassis type.

4. Mount the weapons into the pylons.

5. If you wish you can install a module in for, of robot's head. It will influence the robot's functionality.

6.Indicate the amount of robots of this modification to be built. Depending on your resources you can build several robots instead of one. Indicate the required number next to the button 'Build'.

7. Press the 'Build' button.

Note. If you indicated several robots to be built, they will be manufactured one by one.



Note. Five robots is the maximal size of the queue.

Note. The 'History of robot building' buttons are designed for you to see the previously built robots.

As soon as a robot is manufactured, it appears next to the plant and start waiting for your orders.
