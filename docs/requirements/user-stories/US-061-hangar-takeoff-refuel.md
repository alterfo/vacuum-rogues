# US-061: Ангар — тест компонентов, ремонт, заправка, взлёт

> Эпик: [EPIC-006](../epics/EPIC-006-planet-station-services.md) · Канон: SOURCE-OF-TRUTH §11.4

## User Story
**Как** игрок на планете
**Хочу** перед взлётом видеть состояние корабля и обслужить его
**Чтобы** не стартовать с пустым баком или без двигателя

## Статус: Planned

## Acceptance Criteria
```gherkin
Scenario: Тест-панель готовности
  Given я в ангаре планеты
  Then показан статус ключевых компонентов: Корпус, Топливный бак, Двигатель
  And итог: «Корабль к взлёту готов» либо причина, почему нет

Scenario: Нельзя взлететь без двигателя или баков
  Given на корабле нет двигателя или топливных баков
  Then кнопка «Взлёт» недоступна, показана причина

Scenario: Заправка
  Given бак не полон и у меня хватает кредитов
  When я нажимаю «Заправить бак»
  Then топливо пополняется, списываются кредиты (по объёму дозаправки)

Scenario: Ремонт
  Given корпус повреждён
  When я нажимаю «Ремонт»
  Then прочность корпуса восстанавливается за кредиты

Scenario: Взлёт
  Given корабль готов к взлёту
  When я нажимаю «Взлёт»
  Then переход в SPACE_FLIGHT (выход из системы планеты)
```

## Дизайн (для реализации)
- Новый экран/панель «Ангар» (или секция `PlanetScene`): слева робот-ассистент со
  статусом (зелёные/жёлтые индикаторы), действия Ремонт/Заправка/Взлёт.
- Заправка/ремонт — за кредиты, пропорционально недостающему; взлёт гейтится
  наличием двигателя и баков в снаряжении (см. `ShipLoadout.derivedStats().canTakeOff`
  — двигатель и топливный бак как `Gear` в слотах; легаси-массив `PlayerShip.modules`
  удалён в dual-hull unification).
- Стиль — по образу reference (имена/арт **свои**, не копировать ассеты).

## Затрагиваемые файлы (план)
- `src/presentation/PlanetScene.ts` (+ возможно новый `HangarPanel`/scene)
- `src/domain/PlayerShip.ts` — проверка двигателя/баков, заправка/ремонт
- `src/systems/` — стоимость заправки/ремонта
