Горячие клавиши: планета, ЦР, ВБ, НБ, ПБ, БЦ



Esc — отмена, пауза, вызов системного меню и возврат в игру
F1 — вызов бортового журнала
         Up, Down — навигация
         Page Up, Page Down — навигация
         Mouse Wheel — навигация
         Ctrl+Delete — очистка журнала
         Ctrl+Insert — выгрузить записи из журнала во внешний txt-файл
F2 — записать текущую игру
F3 — загрузить ранее сохраненную игру
F5 — быстрое сохранение
F8 — загрузить быстрое сохранение
F9 — сделать скриншот
F11 — удаление всех прайсов с панели сообщений
F12 — удаление всех сообщений с панели сообщений
S — корабль
        ALT+Mouse 2 — правый клик на предмете в трюме с зажатой клавишей мгновенно перемещение этого предмета на склад
        K — включение/выключение камуфляжа
        Mouse 2 — включение/выключение камуфляжа, кликнуть по корпусу
        Ctrl+цифра от 1 до 3 — запомнить конфигурацию оборудования
        цифра от 1 до 3 — восстановление конфигурации оборудования
        Mouse Wheel — навигация в трюме
        Right, Left — навигация в трюме
R — рейтинг рейнджеров
       Up, Down — навигация
       Page Up, Page Down — навигация
       Mouse Wheel — навигация
I — информационный центр
       Up, Down — навигация
       Page Up, Page Down — навигация
       Mouse Wheel — навигация
       I — поиск
       F — поиск
              Shift+Backspace — стереть весь текст в окне поиска
              Mouse 1 — сохранение результата, при клике на i
Ctrl — при удержании клавиши появление диалога частичной заправки/зарядки
Ctrl+I — перемещение всех вещей из трюма на склад
Ctrl+O — перемещение всех вещей из склада в трюм
U — зарядить ракетное оружие в слотах
Y — зарядить ракетное оружие в трюме
G — здание правительства
       Up, Down — навигация
       Page Up, Page Down — навигация
       Mouse Wheel — навигация
       Insert — сохранение правительственного сообщения
       Mouse 1 — сохранение правительственного сообщения, при клике на i
H — ангар
       F — взлет
       B — заправить бак
       A — ремонт корпуса
T — торговый центр
       Mouse 1 — сохранение прайса, при клике на i
       Home, End — при торговле: максимум, минимум количества товара
       Right, Left — при торговле: увеличение: уменьшение количества товара
       Mouse Wheel — при торговле: увеличение, уменьшение количества товара
E — магазин оборудования
       Right, Left, Up, Down — навигация
       Mouse Wheel — навигация
P — планета (только на планетах)
M — галактическая карта
        Alt — удерживая клавишу, можно мерить расстояния между любыми звездами
Mouse 2 — удаление с панели сообщений, при клике на выполненном задании, прайсе, сообщении
Space — день вперед
Alt+Mouse 2 — правый клик на предмете на складе с зажатой клавишей мгновенно перемещение этого предмета в трюм
Mouse Wheel — навигация в трюме
Up, Down — навигация в трюме
Mouse 2 по предмету — отправить с корабля на склад/перенести со склада на корабль.
Ctrl + Mouse 2 по предмету — быстрая продажа.

ЦР — центр рейнджеров, ВБ — военная база, НБ — научная база, ПБ — пиратская база, БЦ — бизнес центр
