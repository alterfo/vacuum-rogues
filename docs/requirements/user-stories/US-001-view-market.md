# US-001: Просмотр рынка на планете

## User Story
**Как** космический рейнджер
**Хочу** видеть список товаров на рынке планеты с ценами
**Чтобы** принимать решения о покупке и продаже

## Статус: Done

## Acceptance Criteria

```gherkin
Scenario: Игрок открывает рынок на планете
  Given игрок находится на планете
  When игрок нажимает кнопку "Рынок"
  Then отображается список доступных товаров
  And каждый товар показывает цену покупки
  And каждый товар показывает цену продажи
  And видно количество товара на складе планеты

Scenario: Пустой рынок
  Given планета не имеет ресурсов для торговли
  When игрок открывает рынок
  Then отображается сообщение "Товаров нет в наличии"
```

## Technical Context
- **Scene**: TradeScene.ts
- **System**: TradeSystem.ts

- Фильтрация товаров
- История цен
