# UI Bug Fixes: Ship Position on Font Change, JobBoard Scroll, Objects Search

## Overview
Три визуальных бага из плейтеста:
1. При смене размера шрифта (⚙ → S/M/L) корабль прыгает на другую позицию.
2. На Доске заданий нет прокрутки — квесты уходят за экран при ≥4 офферах.
3. Поиск по объектам в Инфоцентре не работает — ввод текста игнорируется.

## Context
- `SpaceFlightScene.onFontScaleChanged()` — передаёт `preserveShipPos` в context, но не выставляет `gameEngine.lastFlightShipPos`. Из-за этого `entryX/Y` инициализируется на краю системы, а teleport идёт позже; малейший timing сдвиг даёт визуальный прыжок.
- `JobBoardPanel` — высота = HEAD+active+availableRows×130+16; на 5 офферах = ~700px; нет scroll.
- `InfoCenterScene.onKeyDown` — проверяет `objectsInputFocused`, но этот флаг не устанавливается автоматически при открытии таба; пользователь должен кликнуть по инпуту отдельно.

Key files:
- `src/presentation/SpaceFlightScene.ts` (onFontScaleChanged ~line 1067)
- `src/presentation/JobBoardPanel.ts` (constructor, render)
- `src/presentation/InfoCenterScene.ts` (renderObjects, onKeyDown, tab click handler)
