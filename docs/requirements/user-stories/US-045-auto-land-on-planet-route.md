# US-045: Авто-посадка, если цель маршрута — планета

> Эпик: [EPIC-004](../epics/EPIC-004-grand-system-radar-background.md) · Канон: SOURCE-OF-TRUTH §3

## User Story
**Как** игрок
**Хочу** чтобы при прокладке маршрута на планету корабль садился на неё по прибытии
**Чтобы** попасть в интерфейс планеты без лишних кликов

## Статус: Done

## Acceptance Criteria
```gherkin
Scenario: Прибытие к планете → посадка
  Given я проложил маршрут на планету и корабль летит
  When корабль достигает планеты (в радиусе посадки)
  Then происходит посадка и переход в интерфейс планеты (SceneType.PLANET)

Scenario: Планета сместилась по орбите
  Given пока я летел, планета ушла по орбите за радиус посадки
  Then корабль до-наводится на текущую позицию планеты и всё равно садится

Scenario: Полёт в открытый космос не приводит к посадке
  Given я кликнул в пустое место (не планета)
  Then по прибытии посадки не происходит
```

## Реализация
`SpaceFlightScene`: поле `routeTargetPlanetId` ставится в `onPlanetClick`,
сбрасывается при навигации в пустоту и в `clearPlannedRoute`. На прибытии
(`updateShip`) при заданном `routeTargetPlanetId` — посадка `onLandOnPlanet`
(в радиусе `LANDING_RANGE`) либо до-наведение на сместившуюся планету.
