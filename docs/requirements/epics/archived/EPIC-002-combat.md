# EPIC-002: Боевая система

## Описание
Тактический бой на гексагональной сетке с пошаговым управлением.

## Бизнес-ценность
Бой - центральная механика игры, создающая напряжение и вызов для игрока.

## User Stories

| ID | Название | Статус |
|----|----------|--------|
| US-010 | Базовая боевая сетка | Done |
| US-011 | Перемещение по гексам | Done |
| US-012 | Атака противника | Done |
| US-013 | AI противников | Planned |
| US-014 | Использование способностей | Planned |
| US-015 | Награды за бой | Planned |

## Acceptance Criteria (Epic Level)
- [ ] Бой происходит на гексагональной сетке 9x9
- [ ] Корабль игрока имеет энергию, щиты, HP
- [ ] AI противников принимает тактические решения
- [ ] После победы игрок получает награду
