# EPIC-003: Живая галактика (NPC-корабли)

> Канон: [SOURCE-OF-TRUTH §6 «Живая вселенная»](../reference/SOURCE-OF-TRUTH.md#6-живая-вселенная-ключевой-принцип).

## Описание
Галактика живёт независимо от игрока. Другие рейнджеры, торговцы, пираты и
патрули летают между системами, берут квесты, торгуют, прокачиваются и
сражаются. Игрок — один из множества акторов, а не центр мира.

## Бизнес-ценность
Ключевая черта оригинала, дающая ощущение живого мира и создающая цели для
взаимодействия (контакт, торговля, бой). Фундамент под боевую систему (EPIC-002):
бой ведётся против конкретного NPC.

## Acceptance Criteria (Epic Level)
- [x] При генерации галактики создаётся пул NPC (детерминированно от seed)
- [x] NPC автономно перемещаются между системами, тратя игровые дни
- [x] Состояние NPC сохраняется и мигрируется в старых сейвах
- [x] NPC видны и движутся в системе игрока, кликабельны (панель контакта)
- [x] NPC дерутся вне экрана (пираты), население восполняется
- [ ] NPC берут квесты и торгуют (после пула квестов / наполнения рынков)
- [ ] Атака NPC запускает тактический бой

## AI: стейт-машина + хук под ONNX
Поведение по умолчанию — детерминированная стейт-машина (`RuleBasedNpcBrain`).
Точка расширения под ONNX — `OnnxNpcBrain` (по образцу `CombatSystem.aiController`),
с фоллбэком на правила. Состояния: `IDLE → TRAVELING → {TRADING|QUESTING|
PATROLLING}`, плюс `FIGHTING`/`DEAD` (будущие срезы).
